# Productivity Apps for Token Buffet

Everyday apps that accept a custom endpoint and can run on your subscriptions.

## 1. Browsers & Launchers

Apps with a bring-your-own-model field.

- **Brave Leo**: Summarize pages and chat; point Bring Your Own Model at the router
- **Raycast**: System-wide AI commands via a custom provider or Ollama host

## 2. Notes & Journals

- **Obsidian LLM Wiki**: Knowledge vault with query and wiki-building plugin
- **Joplin**: Note chat and summaries through the Jarvis plugin
- **Logseq**: Writing assistant through an AI plugin
- **Plume**: Mac journaling over any OpenAI-compatible endpoint

## 3. Email & Documents

- **Thunderbird**: Draft and summarize email with the Ollama Compose extension
- **AnythingLLM**: Private chat over a folder of documents

## 4. Chat Front-Ends

- **Open WebUI**: One ChatGPT-style window over all subscriptions
- **Enchanted / Msty**: Friendly desktop and iOS assistants over an Ollama host

## 5. Smart Home

- **Home Assistant**: Voice assistant through the native Ollama integration
