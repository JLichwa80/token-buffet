# Conference Notes Vault

Sample Obsidian vault with notes from a conference. Includes keynote summaries, session transcripts, presentation highlights, and attendee notes across tax strategy, portfolio management, and investment topics. All dates and attendee names have been anonymized for demonstration purposes.

## Configuration

The vault is pre-configured. Open it in Obsidian after `tbuffet start` (see the [parent README](../README.md)).

- **Plugin settings:** `.obsidian/plugins/karpathywiki/data.json`
- **Registration:** `registered_apps/obsidian/conference-notes/` (apply it again with `tbuffet reconfigure-app obsidian conference-notes`)
- **Router:** `http://127.0.0.1:8090/v1/`
- **Model tiers:** ingest (`fast`), lint (`reasoning`), query (`reasoning`)
- **Vault type:** `finance-conference`
