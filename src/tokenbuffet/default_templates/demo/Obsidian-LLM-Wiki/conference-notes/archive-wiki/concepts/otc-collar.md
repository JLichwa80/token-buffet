## Description
An Over-The-Counter (OTC) Collar is a derivative contract that legally and mechanically fuses a protective put and a covered call into an indivisible single instrument. Standard exchange-traded collars on post-1984 equities can trigger unfavorable [[Straddle Rules]], requiring call premiums to be taxed currently as short-term capital gains while deferring put loss deductions. By fusing these components into a single OTC contract that cannot be separated, this structure eliminates separate component tax recognition and avoids triggering [[Constructive Sale]] rules. Additionally, it enables investors to monetize concentrated, low-basis assets by borrowing against the present value of the protective put, functioning mechanically akin to a [[Variable Prepaid Forward]].
