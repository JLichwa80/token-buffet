# Laddered Diversification Framework

> Stub created by the ingest candidate gate (aside+covered) — [[sources/10-09-panel-discussion_-variable-prepaid-forwards-tax-aware-long-short-an_0f1ad3]] names this without treating it. Will be filled by the next ingest of a source that does.

The laddered diversification framework sequences immediate sales, variable prepaid forwards, and a matched tax-aware long-short book so hedging happens now while taxes are shielded later. Forwards are often settled on January 1 of successive years, which spaces recognition and gives the advisor control of the deferral timeline. The long-short allocation’s octane—its leverage and active risk—is set so loss realization lines up with each maturity; Speaker 3 says that as each forward rolls off, the taxes are completely shielded. The intended end state is a diversified core equity solution that keeps realizing losses, with remaining concentrated shares eventually sellable using harvested losses. The first implementation step recommended in the summary is to set the VPF ladder and settlement dates, then calibrate the long-short to that exact timeline. Clients who expect the stock to keep running may still defer five or ten years and use capital losses whenever recognition arrives.

> "Combine immediate sales, layered VPFs (often January 1 settlements), and tax-aware long-short to hedge now and shield future taxes." — [[sources/10-09-panel-discussion_-variable-prepaid-forwards-tax-aware-long-short-an_0f1ad3]]
