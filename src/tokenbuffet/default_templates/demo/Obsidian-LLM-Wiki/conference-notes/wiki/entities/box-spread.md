# Box spread

## Description
A box spread is an options package that locks in a fixed financing rate. In the practitioner Q&A it is treated as an efficient way to borrow at that fixed rate while generating capital losses. Speaker 2 calls it a fine tool when the client needs financing and does not need a hedge on the concentrated position. The panel contrasts it with the [[Variable Prepaid Forward]], which adds certainty of outcome, avoids margin calls, and is preferred for volatile assets and [[Constructive Sale]] risk. A box spread therefore sits beside variable prepaid forwards and [[Collar]]s as a situation-specific financing instrument, rather than as the default bridge for low-basis stock or Bitcoin. The comparison is part of a broader point that the advisor’s value is matching the tool to whether a hedge, tax deferral, or simple fixed-rate borrowing is required, using [[Client Typology for Strategy Selection]] and keeping [[Straddle Rules]] in view when a collar is the alternative.
