# Using LLMs for code

## Definition

Using LLMs for code is the practice of using large language models, such as Claude and ChatGPT, to help write software.

## Key Characteristics

- Large language models are used as a writing aid for software, not only as a subject of discussion.
- The practice was a recurring theme in Simon Willison's September 2024 output, appearing across his podcast appearances, blog posts, and releases.
- It is linked to the [[llm]] command-line tool and its plugins, which bring LLM access into the developer's shell.
- Willison's TWIML episode focused on using Claude and ChatGPT to write code.

## Applications

- **Podcast discussion:** All three of Willison's September 2024 podcast appearances involved LLMs in some way. The TWIML episode focused on using Claude and ChatGPT to write code.
- **Shell-based workflows:** The [[llm]] command-line tool gives developers LLM access from the terminal, and its plugins extend that access to additional models and tasks.
- **Blog and release activity:** Willison's September 2024 blog posts and releases tied LLM access to the tools he was building, including the [[llm]] command-line tool and its plugins.
