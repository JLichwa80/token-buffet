# Atom feed

## Definition

An Atom feed is a web syndication format that lets readers subscribe to a website's updates and receive new content as it is published, typically through a feed reader.

## Key Characteristics

- A syndication format used to distribute a site's updates to subscribers.
- Lets readers stay up to date on a site without visiting it directly.
- Offered as one subscription option alongside other channels, such as a newsletter.
- Can be generated as an output format by tools, such as the [[datasette-atom]] plugin for [[Datasette]], which adds an Atom output format.

## Applications

- Subscribing to a blog's updates, as Simon Willison's blog offers an Atom feed as a way to stay up to date. The same source presents it as one of two options alongside the [[Substack]] newsletter.
- Publishing data or database query results as a feed, using the [[datasette-atom]] plugin.
