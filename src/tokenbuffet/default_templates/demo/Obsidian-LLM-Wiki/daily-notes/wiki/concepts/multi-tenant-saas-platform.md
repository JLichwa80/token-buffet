# Multi-tenant SaaS platform

> Stub created by the ingest candidate gate (prose+named) — [[sources/2023-08-16-datasette-cloud-weeknotes_9ee111]] names this without treating it. Will be filled by the next ingest of a source that does.

A multi-tenant SaaS platform is a single hosted software service that serves many separate customers, each with isolated data and access. Datasette Cloud is being built this way on Fly. The source says the team will document what they learn about using Fly to build such a platform. This is one of the practical themes that connects the Fly sponsorship to the Datasette Cloud work.

> "Datasette Cloud is already being built on Fly, but as part of Alex’s work we’ll be extensively documenting what we learn along the way about using Fly to build a multi-tenant SaaS platform." — [[sources/2023-08-16-datasette-cloud-weeknotes_9ee111]]
