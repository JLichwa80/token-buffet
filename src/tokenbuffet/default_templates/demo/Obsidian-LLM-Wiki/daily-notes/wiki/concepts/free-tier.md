# free tier

## Definition

A free tier is a no-cost usage allowance offered by an API provider, subject to limits. Usage beyond the allowance is billed, typically per token.

## Key Characteristics

- Provides a no-cost usage allowance rather than an unlimited one
- Is subject to limits, such as a daily request cap and a per-minute rate limit
- Usage beyond the allowance is charged at the provider's regular rates
- Lowers the barrier for developers to try an API before paying

## Applications

- Gemini Pro 1.5 API (April 2024): a free tier allowed up to 50 requests per day, rate limited to 2 requests per minute. Beyond that, usage was billed at $7 per million input tokens and $21 per million output tokens.
- Evaluating or prototyping an LLM API without upfront cost.
