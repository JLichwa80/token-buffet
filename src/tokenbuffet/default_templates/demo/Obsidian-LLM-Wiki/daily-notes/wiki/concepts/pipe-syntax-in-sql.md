# Pipe Syntax in SQL

## Definition

Pipe Syntax in SQL is a proposed new query syntax for SQL, described by [[Google Research]] in the paper "SQL Has Problems. We Can Fix Them". The paper presents it as a fix for SQL's structural limitations.

## Key Characteristics

- Proposed as a new syntax layered on SQL, not a replacement for it in the source's framing.
- Introduced in a PDF paper from Google Research.
- The source notes that Simon Willison used [[Gemini]] 1.5 Pro to convert the PDF to HTML and reported that the first prompt gave a strong result.
- In the source, it is the example that led to a search-ranking outcome and to an unverified clone being hidden from search.

## Applications

- Query authoring in SQL, as the syntax the paper proposes.
- Use as a case study in how a document-conversion workflow (PDF to HTML with an LLM) can be applied to technical papers.
