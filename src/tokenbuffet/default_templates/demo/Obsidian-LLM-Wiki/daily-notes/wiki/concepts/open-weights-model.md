# open weights model

## Definition

An open weights model is a large language model (LLM) whose trained weights are publicly available. The term distinguishes these models from closed, API-only models, which can be used only through a provider's hosted interface.

## Key Characteristics

- The trained model weights are publicly available
- Contrasts with closed, API-only models such as [[GPT-4 Turbo]] and [[Google Gemini Pro 1.5]]
- Examples named in the source include [[Command R+]] from Cohere and [[Mixtral 8x22B]] from Mistral
- Can be ranked alongside closed models on benchmarks such as the LMSYS Chatbot Arena Leaderboard

## Applications

- Comparing model quality: in April 2024, [[Command R+]] reached position 6 on the LMSYS Chatbot Arena Leaderboard, which the source describes as the highest ranking yet for an open weights model.
- Tracking LLM releases by license type, such as Mistral's April 2024 release of [[Mixtral 8x22B]] as a BitTorrent magnet link.
