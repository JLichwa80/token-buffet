# Prompt engineering

## Definition

Prompt engineering is the practice of designing the instructions given to a model to shape its output.

## Key Characteristics

- Works by changing the instructions a model receives, not the model itself.
- Applies to text and image generation alike.
- In this source, it appears in a reverse-engineering case: OpenAI prompt-engineered ChatGPT to write its own image prompts for [[DALL-E 3]].

## Applications

- Image generation: writing and refining prompts for models such as [[DALL-E 3]].
- Getting a model to generate its own prompts, as [[OpenAI]] reportedly did with ChatGPT for DALL-E 3 image requests.
- The author's image-generation experiments, documented in a blog post titled "Now add a walrus". This connects the experiments to the wider interest in how instructions shape model behaviour, and it was one of the main blog themes of the week.
