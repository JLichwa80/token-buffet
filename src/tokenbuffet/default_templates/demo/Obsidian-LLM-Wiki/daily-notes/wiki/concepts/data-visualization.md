# data visualization

> Stub created by the ingest candidate gate (prose+named) — [[sources/2023-12-31-weeknotes_456c53]] names this without treating it. Will be filled by the next ingest of a source that does.

Data visualization is the practice of turning data into charts or graphical displays. In this source it is the purpose of the datasette-plot plugin for Datasette. Alex Garcia introduced the plugin on the Datasette Cloud blog as part of the collaboration between Datasette and Datasette Cloud. The source does not go into the plugin's design beyond its purpose. It shows how Datasette is being extended toward visual analysis of the data it publishes.

> "Alex Garcia released this new plugin for Datasette as part of our collaboration around Datasette Cloud. He introduced it on the Datasette Cloud blog: [datasette-plot—a new Datasette Plugin for building data visualizations](https://www.datasette.cloud/blog/2023/datasette-plot/)." — [[sources/2023-12-31-weeknotes_456c53]]
