# Python packaging

## Definition

Python packaging refers to the tools and processes used to distribute, install, and manage Python libraries and environments.

## Key Characteristics

- Covers distributing libraries, installing them, and managing the environments they run in.
- Is a crowded space with many existing tools.
- New entrants such as [[Rye]] are experimental, and their value can lie in prototyping and advancing discussion of packaging ideas.

## Applications

- Publishing Python libraries so others can install them.
- Installing and resolving a project's dependencies.
- Creating, isolating, and maintaining Python environments for projects.
- Trying out new packaging approaches, such as the experimental tool [[Rye]], to inform wider debate about how packaging should work.
