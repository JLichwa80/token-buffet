# Open source

## Definition

Open source refers to software whose source code is publicly available for anyone to use, modify, and distribute.

## Key Characteristics

- Source code is publicly available.
- Anyone may use the software.
- Anyone may modify the software.
- Anyone may distribute the software, including modified versions.
- Simon Willison treats it as a major theme in software engineering and calls it the biggest productivity boost of his career.

## Applications

- Discussed as a core theme of modern software engineering in the [[Pragmatic Engineer Podcast]] interview with [[Simon Willison]].
- Shared publicly by [[Gergely Orosz]] on Twitter as a clip of Willison's point about its value.
- Forms part of the broader context for how modern software is built, including the role of [[Using LLMs for code]].
