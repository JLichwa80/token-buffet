# Open source sponsorship

## Definition

Open source sponsorship is a funding model in which a company pays for developers to work on open source projects. In the source, [[Fly.io]] sponsors [[Alex Garcia]]'s work on datasette-write-ui and [[Datasette Cloud]]. The sponsorship is tied to documenting what the team learns about building a [[Multi-tenant SaaS platform]] on Fly. The source presents the arrangement as an unusual and encouraging example of this model.

## Key Characteristics

- A company, rather than the open source community, provides the funding.
- The sponsor pays for developers to work on open source projects.
- The sponsored work can be tied to a commercial product, here [[Datasette Cloud]].
- In this example, the sponsorship is linked to sharing knowledge about building a [[Multi-tenant SaaS platform]].

## Applications

- A hosting or cloud provider funds a developer who maintains an open source tool that its customers use.
- A company funds an open source project and publishes what it learns while building on the project's platform.
- A commercial product built on open source software funds the maintainers whose work it depends on.
