# Sentiment analysis

> Stub created by the ingest candidate gate (prose+named) — [[sources/2023-05-01-weeknotes_72fe7e]] names this without treating it. Will be filled by the next ingest of a source that does.

Sentiment analysis is the task of determining whether text expresses a positive, negative or neutral opinion. In this entry Simon Willison set out to run simple sentiment analysis against data in a SQLite database using his tools. The goal was inspired by a Datasette Office Hours conversation. The experiment led to the custom SQL function mechanism added to openai-to-sqlite. The source mentions the task only as a motivation for that work.

> "Inspired by a Datasette [Office Hours](https://simonwillison.net/2021/Feb/19/office-hours/) conversation on Friday I decided to see if I could figure out a way to run simple sentiment analysis against data in a SQLite database using any of my various tools." — [[sources/2023-05-01-weeknotes_72fe7e]]
