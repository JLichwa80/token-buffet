## Core Content

Simon Willison's weeknotes for the week ending 30 October 2023 cover blog posts, research, and plugin releases. The main research thread explored [[entities/pmtiles|PMTiles]] from [[entities/protomaps|Protomaps]] rendered with [[entities/maplibre-gl|MapLibre GL]]. A 2MB extract produced a building-level map of [[entities/half-moon-bay|Half Moon Bay]], which shows that vector maps can be self-hosted on plain static file hosting. He praised [[entities/gpt4all|GPT4All]], whose Python package installs from pre-compiled wheels, and now recommends [[entities/llm-gpt4all|llm-gpt4all]] for running local models. A [[entities/homebrew|Homebrew]] upgrade of [[entities/llm|LLM]] to Python 3.12 broke PyTorch-dependent plugins such as [[entities/llm-embed-jina|llm-embed-jina]]. In response he moved install recommendations to [[entities/pipx|pipx]] and released [[entities/llm-python|llm-python]]. A [[entities/sqlite-migrate|sqlite-migrate]] fix for overlapping migration names changed the schema of the `_sqlite_migrations` table. [[entities/datasette-edit-schema|datasette-edit-schema]] 0.7 added index management for [[entities/datasette|Datasette]] Cloud users. Blog posts covered [[entities/dall-e-3|DALL-E 3]] [[concepts/prompt-engineering|prompt engineering]] and [[concepts/embedding-vector|embeddings]].

## Main Points

- **Self-hosted vector maps:** A single [[entities/pmtiles|PMTiles]] file queried with HTTP range requests lets a 2MB extract serve a building-level map of [[entities/half-moon-bay|Half Moon Bay]] from static hosting.
- **Local LLMs:** [[entities/nomic-ai|Nomic AI]] fixed the debugging-output bug, so [[entities/llm-gpt4all|llm-gpt4all]] is now the recommended way to start running local models.
- **Install breakage:** A [[entities/homebrew|Homebrew]] upgrade to Python 3.12 left [[entities/pytorch|PyTorch]] unavailable, breaking plugins such as [[entities/llm-embed-jina|llm-embed-jina]]. The author switched recommendations to [[entities/pipx|pipx]].
- **New tooling:** [[entities/llm-python|llm-python]] runs a Python interpreter inside [[entities/llm|LLM]]'s virtual environment.
- **Migrations:** [[entities/sqlite-migrate|sqlite-migrate]] 0.1b0 fixed overlapping migration names, which required a conditional check on the `_sqlite_migrations` table. The author argues that [[entities/sqlite-migrate|sqlite-migrate]] with `table.transform()` in [[entities/sqlite-utils|sqlite-utils]] is a robust answer to the limits of [[concepts/alter-table|ALTER TABLE]].
- **Datasette Cloud:** [[entities/datasette-edit-schema|datasette-edit-schema]] 0.7 lets users add and remove indexes on larger tables to speed up faceting.
- **Blog:** The [[entities/dall-e-3|DALL-E 3]] post shows that OpenAI prompt-engineered ChatGPT to generate its own image prompts. The [[concepts/embedding-vector|embeddings]] write-up drew heavy traffic.
