## Core Content

These weeknotes from 10 May 2023 cover three main threads. The first is the release of [[entities/sqlite-utils|sqlite-utils]] 3.31, dated 2023-05-08, which bundled small fixes and pull requests made since the 3.30 release. The second is [[entities/download-esm|download-esm]], a Python CLI tool that downloads the [[concepts/ecmascript-modules|ECMAScript module]] versions of npm packages with their dependencies. It was built as part of an effort to write modern JavaScript without [[concepts/javascript-build-tools|JavaScript build tools]]. The week also included a blog post and transcript, video, and slides from a [[entities/langchain|LangChain]] webinar on [[concepts/prompt-injection|prompt injection]]. A post about a leaked internal [[entities/google|Google]] document led to a [[entities/latent-space|Latent Space]] discussion. The final thread is a prototype for [[concepts/running-python-in-a-denopyodide-sandbox|running untrusted Python in a sandbox]]. It starts a [[entities/deno|Deno]] process from Python and runs [[entities/pyodide|Pyodide]] inside it, which became possible because Deno can now load Pyodide. Pyodide previously ran only in browsers. The approach relates to the wider goal of safe [[concepts/webassembly|WebAssembly]] sandboxing.

## Main Points

- **sqlite-utils 3.31 was released on 2023-05-08.** It bundled fixes and pull requests from the October 2022 3.30 release onward and credits four contributors: Chris Amico, Kenny Song, Martin Carpenter, and Scott Perry.
- The release adds **automatic SpatiaLite detection on Apple Silicon**, a `--raw-lines` option, and fixes to upsert, convert, foreign keys, and transform.
- **download-esm** downloads ECMAScript module versions of npm packages with their dependencies. It supports the goal of writing modern JavaScript without a build tool.
- A **LangChain webinar on prompt injection** was recorded. The author turned the 12-minute introduction into a blog post with a Whisper transcription, video, and slides.
- A **leaked internal Google document** argued that Google and OpenAI have no meaningful moat against fast open source LLM research. The post about it led to a last-minute invitation to a Latent Space Twitter Space.
- The author is prototyping a **safe way to run untrusted Python in a WebAssembly sandbox**. A Deno process started from a Python subprocess runs Pyodide, which Deno can now load.
