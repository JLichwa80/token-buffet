## Core Content

Simon Willison's weeknotes dated 23 April 2024 cover several threads of his recent work. He updated a set of [[entities/llm|LLM]] plugins to support [[entities/llama-3|Llama 3]], which landed on the Thursday before the post. He also wrote up his Stanford talk, [[entities/ai-for-data-journalism|AI for Data Journalism]]. Its twelve live demos included unreleased software that he prepared for release, most notably [[entities/datasette-query-assistant|datasette-query-assistant]], a Claude 3-based plugin that converts English questions into SQL for [[entities/datasette|Datasette]]. Two new draft projects are introduced. [[entities/llm-evals-plugin|llm-evals-plugin]] is an early prototype for running prompt evaluations defined in YAML, and its main missing feature is [[concepts/parameterization|parameterization]]. [[entities/datasette-secrets|datasette-secrets]] stores API keys encrypted in SQLite behind a manage-secrets permission. The secrets work supports a bring-your-own-key model for [[entities/datasette-cloud|Datasette Cloud]] and [[entities/datasette-desktop|Datasette Desktop]] users.

## Main Points

- **Llama 3 plugin updates:** The author updated several [[entities/llm|LLM]] plugins to work with [[entities/llama-3|Llama 3]] and documented how to access it from the terminal.
- **Stanford talk:** The talk [[entities/ai-for-data-journalism|AI for Data Journalism]] had twelve live demos, and several showed unreleased software that was cleaned up for release.
- **Query assistant:** The most notable demo was [[entities/datasette-query-assistant|datasette-query-assistant]], which converts English questions into SQL. Its use case motivates evaluating which models and prompts produce SQL that runs successfully.
- **llm-evals-plugin:** This very early prototype defines evals as YAML files and runs them across models. Its big missing feature is [[concepts/parameterization|parameterization]], which would allow many prompt combinations and examples loaded from CSV, JSON or YAML files.
- **datasette-secrets:** This draft [[entities/datasette|Datasette]] plugin provides an admin UI for API keys, gated by the manage-secrets permission, and stores them encrypted in SQLite.
- **Bring your own keys:** Keys are currently set through environment variables. The author wants [[entities/datasette-cloud|Datasette Cloud]] and [[entities/datasette-desktop|Datasette Desktop]] users to supply their own keys without changing their environment.
