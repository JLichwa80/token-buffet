## Core Content

This weeknotes post by Simon Willison, dated 6 September 2024, covers three threads of his recent work. The first is **client-side JavaScript applications that call LLM APIs directly from the browser**. [[entities/anthropic|Anthropic]] recently added CORS support to its Claude APIs, and [[entities/openai|OpenAI]] and [[entities/gemini|Gemini]] already support it. Anthropic's version needs a special request header. The main trade-off is security: an API key cannot be embedded in a public page, so his tools prompt the user for their own key and store it in [[entities/localstorage|localStorage]]. The tools live in [[entities/simonwtools|simonw/tools]], hosted on [[entities/github-pages|GitHub Pages]], and the Claude-based development relied on [[entities/claude-3-5-sonnet|Claude 3.5 Sonnet]]. The second thread is **converting PDFs to HTML and Markdown with Gemini 1.5 Pro**, which he argues is more readable and accessible than PDF. Examples include a [[entities/google-research|Google Research]] paper on [[concepts/pipe-syntax-in-sql|pipe syntax in SQL]] and a [[entities/nous-research|Nous Research]] report on [[entities/distro|DisTro]]. The third thread covers [[entities/datasette|Datasette]]. While building [[entities/datasette-acl|datasette-acl]] with [[entities/choices-js|Choices.js]], he found that Datasette's core CSS styled every button inside a form, which broke plugins. He is scoping those rules to a core class before Datasette 1.0.

## Key Concepts

- [[concepts/cors|cors]]: The browser mechanism that makes client-side LLM API calls possible.
- [[concepts/claude-artifacts|claude-artifacts]]: Works well with single-file apps when the model is told "no React".
- [[concepts/bounding-boxes|bounding-boxes]]: Gemini Pro's reliable bounding boxes could allow figures to be cropped from PDFs.
- [[concepts/pipe-syntax-in-sql|pipe-syntax-in-sql]]: The new SQL query syntax from the Google Research paper, used as a PDF-conversion test.

## Main Points

- **Anthropic, OpenAI, and Gemini all support CORS**, so LLM APIs can be called from client-side JavaScript. Anthropic requires the `anthropic-dangerous-direct-browser-access` header.
- **API keys should not be embedded in client-side code.** The author has users supply their own key, which is stored in localStorage.
- **Gemini 1.5 Pro converted PDFs to HTML and Markdown with little effort.** The conversions covered a Google Research paper and a Nous Research report.
- **PDFs are poor for mobile reading and accessibility**, so LLM-based conversion to HTML is a practical fix.
- **Gemini Pro's bounding-box support** could enable automatic extraction of figures from PDF pages.
- **Datasette's core CSS styled every button inside a form**, which broke plugins such as datasette-acl with Choices.js. The fix is to scope these rules to a core class before Datasette 1.0.
- **Single-file vanilla HTML and JavaScript apps suit LLM-assisted editing**, and Claude Artifacts work well with that style.
