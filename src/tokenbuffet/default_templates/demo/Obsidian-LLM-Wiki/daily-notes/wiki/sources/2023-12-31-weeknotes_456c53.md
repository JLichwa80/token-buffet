## Core Content

Simon Willison's final weeknotes of 2023, dated 31 December, wrap up his December activity across [[entities/datasette|Datasette]], [[entities/llm|LLM]], and his blog. The headline item is [[entities/datasette-plot|datasette-plot]], a visualization plugin that [[entities/alex-garcia|Alex Garcia]] built as part of the Datasette Cloud collaboration. The post also links three blog entries: one on [[concepts/prompt-injection|prompt injection]] mitigation by limiting its blast radius, one on running [[entities/mistral|Mistral]] models through LLM, and one on the [[concepts/ai-trust-crisis|AI trust crisis]], where [[entities/dropbox|Dropbox]] learned how sensitive users are to uncertainty about training data. The release section lists mostly minor fixes plus a few notable updates: a read-only JSON API for [[entities/django-sql-dashboard|Django SQL Dashboard]], load-extension support in [[entities/sqlite-utils-shell|sqlite-utils-shell]] for [[entities/steampipe-extensions|Steampipe extensions]], a higher-quality text-to-speech option in [[entities/ospeak|ospeak]], and easier use of [[concepts/gguf|GGUF]] models in [[entities/llm-llama-cpp|llm-llama-cpp]]. The post closes with two TILs, on Steampipe extensions and on editing iPhone home screens on macOS.

## Key Entities

- [[entities/datasette|Datasette]]: the open source multi-tool at the center of most releases and plugins in the post.
- [[entities/llm|LLM]]: the command-line tool and plugin framework for running language models.
- [[entities/alex-garcia|Alex Garcia]]: developer who released datasette-plot.
- [[entities/datasette-plot|datasette-plot]]: new Datasette plugin for building data visualizations.
- [[entities/mistral|Mistral]]: model provider whose models can be run through LLM.
- [[entities/django-sql-dashboard|Django SQL Dashboard]]: Django app for building dashboards from raw SQL, now with a read-only JSON API.
- [[entities/sqlite-utils-shell|sqlite-utils-shell]]: interactive shell for sqlite-utils, now supporting `--load-extension`.
- [[entities/steampipe|Steampipe]]: the tool whose extensions can now be loaded into SQLite.
- [[entities/steampipe-extensions|Steampipe extensions]]: plugins that run inside SQLite through sqlite-utils-shell.
- [[entities/ospeak|ospeak]]: command-line text-to-speech tool, gaining a higher-quality `tts-1-hd` option.
- [[entities/llm-llama-cpp|llm-llama-cpp]]: LLM plugin for running models through llama.cpp, now loading GGUF files directly.
- [[entities/llama-cpp|llama.cpp]]: the runtime that llm-llama-cpp uses.
- [[entities/anyscale-endpoints|Anyscale Endpoints]]: hosted model service that the llm-anyscale-endpoints plugin supports.
- [[entities/dropbox|Dropbox]]: cited as a cautionary example in the AI trust crisis post.

## Key Concepts

- [[concepts/prompt-injection|Prompt injection]]: malicious input that makes a language model act against its instructions; mitigated by limiting blast radius.
- [[concepts/ai-trust-crisis|AI trust crisis]]: loss of user confidence when people are unsure whether their data trains AI models.
- [[concepts/plugin-system|Plugin system]]: the extension architecture that lets LLM and Datasette add providers and runtimes as plugins.
- [[concepts/gguf|GGUF]]: a model file format used with llama.cpp-based tools.
- [[concepts/text-to-speech|Text-to-speech]]: converting written text into spoken audio, as in ospeak.
- [[concepts/data-visualization|Data visualization]]: the goal of the datasette-plot plugin.
- [[concepts/haversine-distance|Haversine distance]]: great-circle distance calculation exposed as a SQL function by datasette-haversine.

## Main Points

- **datasette-plot** is the headline development of the month: a Datasette plugin for data visualization, released by Alex Garcia as part of the Datasette Cloud collaboration.
- **LLM plugins are paying off.** The post cites [[entities/mistral|Mistral]] model support in LLM as an example of the [[concepts/plugin-system|plugin system]] working well.
- **[[concepts/prompt-injection|Prompt injection]]** mitigation is framed as limiting blast radius, from a podcast episode with Kate Holterhoff.
- **The [[concepts/ai-trust-crisis|AI trust crisis]]:** Dropbox shows how sensitive users are to any doubt about whether their data trains a model.
- **Django SQL Dashboard 1.2** adds a read-only JSON API for saved dashboards, which makes quick ad-hoc AI work on Django PostgreSQL data easy.
- **sqlite-utils-shell 0.3** adds `--load-extension`, so [[entities/steampipe-extensions|Steampipe extensions]] can be used in SQLite.
- **ospeak 0.3** adds `-m tts-1-hd` for higher-quality [[concepts/text-to-speech|text-to-speech]] output, via a PR from Mikolaj Holysz.
- **llm-llama-cpp** can load a [[concepts/gguf|GGUF]] model file directly, which makes trying new local models much quicker.
