## Core Content

Simon Willison's weeknotes for the roughly two and a half weeks before 16 July 2023 center on a new major version of [[entities/llm|llm]], his command-line tool for working with large language models. LLM now accepts plugins that add models beyond OpenAI, including [[entities/self-hosted-language-models|self-hosted language models]], and it gains a Python API that works the same way for hosted and local models. Willison released three model plugins: [[entities/llm-gpt4all|llm-gpt4all]] (17 models from [[entities/gpt4all|GPT4All]]), [[entities/llm-palm|llm-palm]] (Google's [[entities/palm-2|PaLM 2]]), and [[entities/llm-mpt30b|llm-mpt30b]] (MPT-30B). He also wrote a detailed tutorial on [[concepts/writing-a-plugin-to-support-a-new-model|writing a model plugin]], because generative AI documentation is sparse.

The post also covers a 2hr45m tutorial, [[entities/data-analysis-with-sqlite-and-python|Data analysis with SQLite and Python]], now hosted on the [[entities/datasette|Datasette]] tutorials site. Other releases include [[entities/datasette-render-markdown|datasette-render-markdown]] 2.2, [[entities/symbex|symbex]] 1.1, and [[entities/ttok|ttok]] 0.2. The tutorial's table-of-contents feature was written entirely with [[entities/chatgpt-code-interpreter|ChatGPT Code Interpreter]].

## Main Points

- **LLM 0.5 adds a plugin system**, so models beyond OpenAI, including self-hosted models, work through the tool and its Python API.
- **Three model plugins were released on 2023-07-12:** llm-gpt4all (17 GPT4All models), llm-palm (Google PaLM 2), and llm-mpt30b (MPT-30B).
- **Plugin tutorial:** Willison wrote a comprehensive guide to building LLM model plugins and hopes others will follow it.
- **SQLite and Python tutorial:** the 2hr45m data analysis tutorial moved to the Datasette tutorials site, with video and an improved handout.
- **datasette-render-markdown 2.2** adds a custom Jinja block tag and an automatic nested table of contents, built with ChatGPT Code Interpreter.
- **symbex 1.1** adds a `--check` mode for continuous integration and a `--rexec` option that pipes symbol bodies through a shell command.
- **ttok 0.2** adds encode and decode options for inspecting GPT tokens.
