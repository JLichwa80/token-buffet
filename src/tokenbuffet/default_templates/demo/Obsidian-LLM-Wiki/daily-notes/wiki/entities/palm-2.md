# PaLM 2

## Description

PaLM 2 is Google's large language model, accessed through Google's API in the setup described in Simon Willison's 2023-07-16 weeknotes. Willison built the [[llm-palm]] plugin to add PaLM 2 to [[LLM]], his command-line tool for working with language models. The post lists it as one of three non-OpenAI model plugins released on 2023-07-12, alongside llm-gpt4all and llm-mpt30b. It is cited as an example of a hosted model, as opposed to a self-hosted one, that LLM supports through its plugin architecture.
