# Armin Ronacher

## Description

Armin Ronacher is the author of [[Rye]], an experimental new approach to Python packaging, which he published on GitHub under the handle mitsuhiko. In the source, he is described as having been quite apologetic about Rye and as having publicly asked whether Rye should exist, given how crowded the Python packaging space is. [[Simon Willison]] argues that a working prototype of an interesting idea is always worthwhile, and he credits Ronacher with the most interesting idea in Rye: bundling Python itself rather than depending on a system Python. Ronacher appears in the source only as Rye's creator, so his role is tied to that project. The relationship is one of creator and commentator on the same tool.
