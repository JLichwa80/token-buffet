Steampipe is a tool whose extensions the author wanted to use inside SQLite-based tools. The post links a TIL titled Running Steampipe extensions in sqlite-utils and Datasette, dated 2023-12-21. The motivation for the sqlite-utils-shell change was to make Steampipe extensions usable there. Steampipe is therefore a integration target rather than the main subject of the post. Its extensions are a way to extend SQLite with external data sources.
