# GitHub Universe

## Description

GitHub Universe is GitHub's conference. Simon Willison spoke there on Wednesday of the second week of November 2023, giving a ten-minute talk titled "Financial sustainability for open source projects." The day before, he attended a GitHub Universe pre-summit for open source maintainers. He later published an annotated version of the talk and noted that a ten-minute talk required a lot of editing and planning. The event marks the end of his conference run for the year.
