# Mistral Large

## Description

Mistral Large is a large language model released by [[Mistral]]. The source is Simon Willison's weeknote dated 2024-02-27, which says Mistral released Mistral Large "this morning". The same weeknote lists [[llm-mistral]] 0.3, dated 2024-02-26, which added support for the model to the `llm` command-line tool. The source gives the usage as `llm -m mistral-large 'Prompt goes here'`, after installing the plugin with `llm install llm-mistral --upgrade` and setting a Mistral API key. The model's release is the reason the llm-mistral update appears in this weeknote.
