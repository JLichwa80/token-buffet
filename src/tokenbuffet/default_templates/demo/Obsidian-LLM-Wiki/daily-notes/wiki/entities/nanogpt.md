# nanoGPT

## Description

nanoGPT is an open-source GPT-style language model training project by Andrej Karpathy. In the 9 February 2023 weeknotes, [[Simon Willison]] used it to train and run a generative language model on a MacBook M2, which he said "trains really nicely on an M2." The model was trained from scratch rather than from a pre-existing language model. Trained on the full text of Willison's blog, the output was "total junk" that still had "a hint of my voice." Willison notes that producing meaningful sentences would need far more text and training time. The TIL on running nanoGPT is one of the main research results of that week, alongside [[gtr-t5-large|gtr-t5-large]] embeddings work.
