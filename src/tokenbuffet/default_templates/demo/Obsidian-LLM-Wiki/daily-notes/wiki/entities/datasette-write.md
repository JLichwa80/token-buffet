# datasette-write

## Description

datasette-write is a [[Datasette]] plugin that provides a UI for executing SQL writes against a database. In the 2024-09-06 weeknotes, it gained a row action menu item that updates a selected row using a pre-canned UPDATE query. The author cites it as an example of revisiting older plugins during the Datasette form-styling work, which led to finishing features that were only partially complete. It was one of the plugins that needed updating after the core CSS change. It is related to [[datasette-acl]], another Datasette plugin.
