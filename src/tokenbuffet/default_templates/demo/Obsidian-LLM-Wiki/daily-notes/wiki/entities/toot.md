# toot

## Description

toot is a Python library and command-line tool for [[Mastodon]]. The author found it while checking for package names on PyPI. He had planned to write a small Python CLI for posting to Mastodon, a Mastodon version of his tweet-images utility, but toot already did more than that planned tool. He used toot for his Mastodon bot, which posts a screenshot of Covid sewage numbers each morning. The bot runs on scheduled GitHub Actions, and the setup is explained in the [[TIL]].
