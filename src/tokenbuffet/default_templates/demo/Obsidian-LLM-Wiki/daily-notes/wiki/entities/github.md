# GitHub

## Description

GitHub hosts the source code repositories for [[Datasette]], [[LLM]], and [[sqlite-utils]], the projects discussed in these weeknotes. It also publishes the security advisories and release pages that the source links to. The source describes GitHub as a CVE Numbering Authority, meaning its security team reviews advisories and issues CVEs. [[Datasette]] 1.0 alpha vulnerability was disclosed by Simon Willison through a GitHub security advisory, linked to [[CVE-2023-40570]]. GitHub's public API is also used in the source as the example of link header pagination.
