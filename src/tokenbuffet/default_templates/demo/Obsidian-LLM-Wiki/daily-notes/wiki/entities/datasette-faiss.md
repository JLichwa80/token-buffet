# datasette-faiss

## Description

datasette-faiss is a Datasette plugin that builds and maintains a FAISS index for specified tables. It was released as version 0.1a0 on 11 January 2023. The plugin enables fast vector similarity search over the document corpus used in the Q&A experiment. It is one of the four software releases the post ties directly to the documentation Q&A work. It connects Datasette's table handling with [[FAISS]]'s search capabilities, which makes it a bridge between [[Datasette]] and [[FAISS]].
