# datasette-create-view

## Description

datasette-create-view is a [[Datasette]] plugin, released as version 0.1 on 2024-03-07, that lets users create a SQL view from a SQL query. Its development depended on the new `query_actions()` [[plugin hook]], which Simon Willison shipped for this purpose. The plugin is one of the highlighted releases in the 2024-03-16 weeknotes. It shows how the [[action buttons]] work described in the post was used to build new Datasette features.
