# llm-palm

## Description

llm-palm is an [[LLM]] plugin that adds support for Google's [[PaLM 2]] language model through Google's API. Simon Willison released it as version 0.1 on 2023-07-12, and it is one of three model plugins listed in the weeknotes post. It is an example of a hosted, non-OpenAI model added to LLM through the plugin system. The post presents it as evidence that the plugin architecture works beyond OpenAI.
