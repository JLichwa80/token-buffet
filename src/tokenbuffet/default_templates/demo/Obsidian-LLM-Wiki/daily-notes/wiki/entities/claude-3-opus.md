# Claude 3 Opus

> Stub created by the ingest candidate gate (prose+named) — [[sources/2024-09-06-weeknotes_32f8a8]] names this without treating it. Will be filled by the next ingest of a source that does.

Claude 3 Opus is an Anthropic model in the Claude 3 family that the source names as the model used to build the Haiku demo tool. The source says the Haiku project was put together a few months before the post using this model. It is one of several Claude models mentioned in the context of AI-assisted development. Its role in the source is as a comparison point to the newer Claude 3.5 Sonnet and Claude 3 Haiku.

> "All three of these tools made heavy use of AI-assisted development: Claude 3.5 Sonnet wrote almost every line of the last two, and the Haiku one was put together a few months ago using Claude 3 Opus." — [[sources/2024-09-06-weeknotes_32f8a8]]
