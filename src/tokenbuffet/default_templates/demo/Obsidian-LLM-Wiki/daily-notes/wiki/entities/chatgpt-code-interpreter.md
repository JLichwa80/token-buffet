# ChatGPT Code Interpreter

## Description

ChatGPT Code Interpreter is a [[ChatGPT]] feature that writes Python code from a natural-language description and can execute that code to check whether it works. Simon Willison wrote the code for the table-of-contents feature of the [[Data analysis with SQLite and Python]] tutorial entirely with it, and he shared the transcript of that session. In his 2023-07-16 weeknotes he says he had been using it for a few months and calls it "the most interesting thing in the whole AI space at the moment". Willison also discussed it on a Latent Space episode that drew 17,000 listeners on Twitter Spaces. The feature is provided by [[OpenAI]].

Willison also noted that the environment has no internet access, but he found a way to install extra Python packages into it. He uploaded Deno and Lua binaries so the feature could run code in those languages too. He had been using it to run micro-benchmarks, and in his 2023-05-01 weeknotes he called it "the most interesting thing in all of ChatGPT/LLM world at the moment".
