# CLIP

## Description

CLIP is an image and text embedding model. [[LLM]] gained binary embedding support for CLIP in version 0.10. Simon Willison uses CLIP as the basis for [[llm-clip]], a plugin that generates [[Embeddings]] for both images and text. According to the source, CLIP makes it possible to build an image search engine that runs entirely on the user's own computer. In the source, CLIP is one of the main examples of the embedding work Willison has been doing across LLM and its plugins.
