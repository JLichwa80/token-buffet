# PhotoSwipe

## Description

PhotoSwipe is a JavaScript image gallery library. The author adopted it to upgrade the photo galleries on the [[Niche Museums]] site during this week's work, replacing the earlier gallery display. The author first tested PhotoSwipe on their own blog before using it on Niche Museums. The source mentions PhotoSwipe as the tool behind the display change, not as a subject in its own right. The gallery work was done alongside the [[EXIF data|EXIF photo-metadata work]] on the same project.
