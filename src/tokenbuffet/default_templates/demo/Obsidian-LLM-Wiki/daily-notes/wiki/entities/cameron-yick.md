# Cameron Yick

## Description

Cameron Yick is the author of the JavaScript Plugin API pull request for [[Datasette]], a project that had been in development for months before the PR was submitted. The work adds custom panels above the main table view and extra options to the column "cog" action menu. Cameron's JavaScript plugin mechanism is modeled on pluggy, the Python plugin framework that Datasette already uses. Simon Willison describes the work as a really exciting new piece of the puzzle for richer Datasette plugins.
