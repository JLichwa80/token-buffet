# PyCon

## Description

PyCon is the Python programming language conference, and the 2023 edition was held in Salt Lake City. [[Simon Willison]] flew there after giving his [[Citus Con]] keynote, then gave a three-hour workshop on Wednesday titled "Data analysis with SQLite and Python". The workshop materials were published in a separate post, which the weeknotes link to as the first entry of the week. The post describes the conference as a busy part of his speaking week, followed by time spent catching up with old friends and talking about Python. PyCon is the main in-person event the post covers.
