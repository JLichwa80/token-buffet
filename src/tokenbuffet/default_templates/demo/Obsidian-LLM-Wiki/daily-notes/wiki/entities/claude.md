# Claude

## Description

Claude is a large language model from [[Anthropic]], accessed by [[Simon Willison]] through an API during the period covered by his weeknotes. The source notes that Claude has a 100,000 token context limit, which compares favourably with the 8,000 token default for [[GPT-4]]. Willison uses Claude with [[LLM]] to summarize [[Hacker News]] comment threads into themes with attributed quotes. He reports that spot checks of those quotes have not turned up any hallucinations.

- [[Simon Willison]] was still on the waiting list for the official Claude API, so he paid for Claude access through OpenRouter instead, using the llm-openrouter plugin, and reported that it works just fine.
- Claude's 100,000 token context makes it a really great option for working with larger documents.
