# DisTro

## Description

DisTro is a technology developed by [[Nous Research]] for distributed training of LLMs over low-bandwidth connections. In the source, it appears only through a preliminary report PDF that Nous Research released about the technology. [[Simon Willison]] ran that PDF through [[Gemini]] 1.5 Pro to produce a Markdown version of the report, which he noted even handled tables. The source uses DisTro as one of two examples of PDF-to-Markdown conversion, supporting his argument for HTML and Markdown over PDF.
