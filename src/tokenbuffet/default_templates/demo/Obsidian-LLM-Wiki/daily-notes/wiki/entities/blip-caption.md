# blip-caption

## Description

blip-caption is a small command-line tool, released as version 0.1 on 2023-09-10, for generating image captions. It wraps the [[Salesforce BLIP|Salesforce BLIP]] model so that captions can be produced directly from the terminal. [[Simon Willison]] built it after finding BLIP easy to work with. It is a concrete example of the quick, single-purpose tools he builds around new models.
