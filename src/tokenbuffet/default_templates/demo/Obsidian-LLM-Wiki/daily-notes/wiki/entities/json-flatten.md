# json-flatten

## Description

json-flatten is a Python library created by Simon Willison for converting key/value pairs into nested JSON objects. The source presents it as an earlier attempt at the problem that the new [[Datasette]] `--setting` option solves. Willison says he took a slightly different approach in the `--setting` work, which is why json-flatten is not used there. It is a background reference in the source rather than a central subject.
