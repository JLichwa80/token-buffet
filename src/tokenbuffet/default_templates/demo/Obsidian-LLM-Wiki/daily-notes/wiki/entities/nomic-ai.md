# Nomic AI

## Description

Nomic AI is the company behind [[entities/gpt4all|GPT4All]], a free, locally running chatbot project. According to the source, Nomic took [llama.cpp](https://github.com/ggerganov/llama.cpp) and other libraries and wrapped them in a much nicer experience, with Windows, macOS and Ubuntu installers. Nomic also released the GPT4All Python core as an installable package and published compiled binary wheels to PyPI, so that `pip install gpt4all` works without a compiler toolchain. The author credits Nomic with fixing the debugging-output bug in the [[entities/llm-gpt4all|llm-gpt4all]] plugin, which makes that plugin the recommended way to start running local models. Nomic also made a large GPU release in September that the latest version of the plugin can use on macOS.
