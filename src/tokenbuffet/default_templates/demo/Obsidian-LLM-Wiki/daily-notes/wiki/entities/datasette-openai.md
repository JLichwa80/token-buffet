# datasette-openai

## Description

datasette-openai is a Datasette plugin that provides custom SQL functions for querying OpenAI APIs, so SQL queries can call OpenAI directly. It was released as version 0.2 on 14 January 2023, with four releases in total. It is the core component that lets the documentation Q&A experiment call OpenAI from within SQL, and it is one of the main outputs of that experiment. The plugin depends on the custom SQL functions mechanism that [[Datasette]] provides. Its release is the first item in the week's software release list in the source weeknotes.
