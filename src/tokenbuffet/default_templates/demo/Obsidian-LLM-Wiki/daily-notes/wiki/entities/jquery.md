# jQuery

## Description

jQuery is a JavaScript library. In the source, Simon Willison cites it as a model for how software can handle major version upgrades. He admires how jQuery uses plugins to keep older features working on an opt-in basis after a major release. He says he wants to apply the same pattern to [[entities/sqlite-utils|sqlite-utils]], which led to the [[entities/sqlite-utils-fast-fks|sqlite-utils-fast-fks]] plugin. jQuery appears only as an inspiration and is not otherwise part of the Datasette or LLM work described in the source.
