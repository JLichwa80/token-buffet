# AI for Data Journalism

## Description

AI for Data Journalism is a talk Simon Willison gave at Stanford, titled "demonstrating what we can do with this stuff right now." It was built around 12 live demonstrations of LLM-based tools. Several demos showed software that had not yet been released, so Willison spent time preparing that software for release, including the [[datasette-query-assistant]] plugin. He later wrote up the talk as a blog post and linked a recording of the demo section. The talk is the source of the release work described in the related weeknote and ties the [[datasette-query-assistant|Query Assistant]] plugin to the wider data journalism use case.
