# MacWhisper

## Description

MacWhisper is a macOS transcription application. Simon Willison used it to produce a transcript of his [[WordCamp US]] keynote. He combined its output with his annotated presentation tool to create a detailed transcript that includes extra links and context. The source mentions MacWhisper only as a tool in this workflow, not as a subject of analysis. It is linked to the WordCamp US keynote and to the [[Large Language Models]] talk that the transcript covers.
