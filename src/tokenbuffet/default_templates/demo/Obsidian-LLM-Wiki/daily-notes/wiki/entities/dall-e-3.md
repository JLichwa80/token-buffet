# DALL-E 3

## Description

DALL-E 3 is an image generation model developed by [[OpenAI]]. In the source, the author covers it in a blog post about [[Prompt engineering]]. The post's reverse engineering shows that OpenAI prompt-engineered [[ChatGPT]] to write its own image prompts for DALL-E 3. The source lists the post among the blog posts of that week, alongside a write-up on embeddings. The source does not describe the model's architecture or capabilities beyond this.
