# Salesforce BLIP

## Description

Salesforce BLIP is an image captioning AI model. Simon Willison tried it after noticing that the Hugging Face most-downloaded models list is a good guide to easy-to-use models. He found it produced usable captions for images and described it as easy to work with. This experience prompted him to build a small CLI tool around the model, which was released as the [[blip-caption]] plugin. The model is hosted on [[Hugging Face]].
