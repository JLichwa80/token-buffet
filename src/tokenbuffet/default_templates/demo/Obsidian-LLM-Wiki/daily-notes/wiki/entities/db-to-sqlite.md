# db-to-sqlite

## Description

db-to-sqlite is a command-line tool maintained by Simon Willison for exporting tables or queries from any SQL database into a SQLite file. The weeknotes from 2023-02-09 list version 1.5 as a release dated 2023-02-07, and note that the project already had 17 releases in total. In the source it appears under "Releases this week," alongside [[datasette-explain]] and [[shot-scraper]]. The source treats it as a release announcement rather than discussing it in detail. Its output format is [[SQLite]].
