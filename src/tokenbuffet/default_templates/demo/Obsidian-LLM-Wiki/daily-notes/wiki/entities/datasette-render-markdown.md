# datasette-render-markdown

## Description

datasette-render-markdown is a Datasette plugin for rendering Markdown. Simon Willison released it as version 2.2 on 2023-07-02. This release adds a custom Jinja block tag that renders its contents as Markdown. Willison developed the tag while building the [[Data analysis with SQLite and Python]] tutorial. The plugin appears in the release list of that post. It is connected to the custom Jinja tag pattern that Willison documented in a TIL.
