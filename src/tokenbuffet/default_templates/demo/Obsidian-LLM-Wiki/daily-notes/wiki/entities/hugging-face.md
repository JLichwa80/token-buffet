# Hugging Face

## Description

Hugging Face is a company that hosts machine learning models. In Willison's [[Embeddings]] experiments it was a key source of models. He recommends its all-models page, sorted by downloads, as a practical guide to which models are easy to use. He tried the Salesforce BLIP image captioning model from the platform and built the blip-caption CLI tool to wrap it. He also wrote a TIL on running [[Datasette]] on Hugging Face Spaces, which offers free scale-to-zero hosting with 16GB of RAM for Docker containers.
