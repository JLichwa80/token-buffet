# Fly.io

## Description

Fly.io is a hosting company that sponsors [[Alex Garcia]]'s work on [[Datasette Cloud]] features. According to the source, the sponsorship is the reason Garcia can build out the social and collaboration features for Datasette Cloud. Fly.io is also presented as a hosting option for Datasette projects. In the source it appears only as a sponsor and hosting option, so its role is peripheral to the main technical themes.

Datasette Cloud already runs on Fly, and the Datasette team plans to document what it learns about building a multi-tenant SaaS platform on Fly. Alex Garcia also has work in the pipeline with Fly's Litestream project, which the Datasette team hopes to discuss in more detail soon.
