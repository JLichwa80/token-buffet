# Protomaps

## Description

Protomaps is an open project for producing and distributing openly licensed vector map data. The author describes it as absolutely fantastic technology after seeing it discussed on Hacker News. Its [[PMTiles]] format is the core mechanism that makes the project useful. Protomaps provides builds of a large world map and a guide for extracting a smaller area. The author used it to build a self-hosted vector map of [[Half Moon Bay]], rendered in the browser with [[MapLibre GL]].
