# FAISS

## Description

FAISS is a library for fast vector similarity search. It is the engine behind the [[datasette-faiss]] plugin, which maintains a FAISS index for specified [[Datasette]] tables. That index makes vector search practical inside a Datasette instance. In the documentation Q&A experiment, the author combined FAISS with GPT-3 embeddings to find semantically similar documents. FAISS is a supporting technology in that post rather than its main subject.
