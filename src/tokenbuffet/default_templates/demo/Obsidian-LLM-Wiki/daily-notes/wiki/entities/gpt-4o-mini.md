# GPT-4o mini

## Description

GPT-4o mini is a hosted large language model from OpenAI, released on 19 July 2024, the day Simon Willison published the weeknotes that cover it. Willison describes it as the cheapest of the high-performing hosted models, cheaper even than Claude 3 Haiku and Gemini 1.5 Flash. Its most notable characteristic is a 16,000 token output limit. Willison shipped [[LLM]] 0.15 to add support for the model, and the release made GPT-4o mini the default model in LLM, replacing GPT-3.5 Turbo.
