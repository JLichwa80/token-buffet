# simonw/tools

## Description

simonw/tools is Simon Willison's GitHub repository of pure HTML and JavaScript tools, published on GitHub Pages at tools.simonwillison.net. Each tool is a single file that needs no server-side hosting, which the author values for its simplicity. Several tools call LLM APIs directly from the browser, including haiku, gemini-bbox, and gemini-chat, linking the collection to [[Anthropic]] and [[Gemini]]. The repository is the home base for the client-side approach described in the source post. It is also the main place where the author publishes AI-assisted development experiments.
