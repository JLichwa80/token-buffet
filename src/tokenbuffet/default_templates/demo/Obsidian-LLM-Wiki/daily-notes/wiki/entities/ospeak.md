# ospeak

## Description

ospeak is a command-line tool for running text-to-speech through OpenAI Text to speech, and it is maintained by its author, Simon Willison. Version 0.3, listed on 2023-12-13, added the `-m tts-1-hd` option, which produces higher-quality output. The change came from a pull request by Mikolaj Holysz. ospeak is one of several small command-line tools in the author's portfolio. It is an example of [[concepts/text-to-speech|text-to-speech]] applied from the terminal.

ospeak 0.2 was released on 2023-11-07 as a CLI tool for running text through OpenAI Text to speech. Release listings also refer to this version as "ospeak 0.2".

The author built ospeak on the evening of OpenAI DevDay (Monday, 6 November 2023) as a command-line tool for OpenAI's new text-to-speech API. That same day he shipped [[entities/llm|LLM]] 0.12 with support for the new GPT-4 Turbo model. ospeak is one of the tools he built in response to the [[entities/openai-devday|OpenAI DevDay]] announcements.
