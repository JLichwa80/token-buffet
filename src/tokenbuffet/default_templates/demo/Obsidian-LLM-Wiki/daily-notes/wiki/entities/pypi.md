# PyPI

> Stub created by the ingest candidate gate (prose+named) — [[sources/2023-02-09-weeknotes_05bd6f]] names this without treating it. Will be filled by the next ingest of a source that does.

PyPI is the Python Package Index, the public repository where Python packages are published and searched. In the source, Simon Willison checked PyPI for available package names before building a small Mastodon CLI tool. That search turned up the toot library, which he judged to be a superset of the tool he had planned. PyPI thus indirectly led to the decision to use toot.

> "I was about to build a new tiny Python CLI tool for this, but in checking for available names on PyPI I found [toot](https://toot.readthedocs.io/) which is a superset of the tool I had been planning to build myself (a Mastodon version of my [tweet-images](https://github.com/simonw/tweet-images) utility.)" — [[sources/2023-02-09-weeknotes_05bd6f]]
