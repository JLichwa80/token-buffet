# llm-anyscale-endpoints

## Description

llm-anyscale-endpoints is a plugin for [[LLM]] that provides access to models hosted by [[Anyscale Endpoints]]. It was released in version 0.2. The plugin follows the same structure as [[llm-openrouter]] and uses the same OpenAI-compatible approach. The author notes that the core code is less than 30 lines. The plugin was built quickly and shows how LLM can be extended to new hosted backends.
