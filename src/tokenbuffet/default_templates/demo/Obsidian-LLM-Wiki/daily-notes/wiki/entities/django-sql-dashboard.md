# Django SQL Dashboard

## Description

Django SQL Dashboard is a Django app for building dashboards from raw SQL queries. In December 2023 it gained a read-only JSON API for saved dashboards, which the author highlighted as a notable release. The author describes the API as a way to quickly set up ad-hoc AI work on data in a Django PostgreSQL database. Its 1.2 release is listed on 2023-12-16. It is one of the author's data tools, in the same family as [[Datasette]].
