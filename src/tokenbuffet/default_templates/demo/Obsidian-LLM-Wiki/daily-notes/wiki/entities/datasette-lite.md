# Datasette Lite

## Description

Datasette Lite is a web application that runs [[Datasette]] entirely in the browser using a Python build compiled to WebAssembly. In the [[sources/2023-02-09-weeknotes_05bd6f|2023-02-09 weeknotes]], it is cited to show that several WebAssembly builds of Python exist and that the author uses one of them there. The author's interest in running Python WASM in a sandbox on his own machine grew out of this experience. The post links to an earlier article about Datasette Lite from May 2022. Datasette Lite is a related project to Datasette, which is the main subject of the same week's work.
