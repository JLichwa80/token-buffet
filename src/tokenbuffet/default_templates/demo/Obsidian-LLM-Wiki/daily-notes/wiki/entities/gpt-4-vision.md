# GPT-4 Vision

## Description

GPT-4 Vision is OpenAI's image-input capability for GPT-4 models. Before April 2024 it was a separate model, but on April 9, 2024 OpenAI integrated it directly into [[GPT-4 Turbo]] when it released the non-preview version of that model. The source reports that vision mode now also supports function calling and JSON output, which were previously unavailable for image inputs. The capability is central to the author's [[datasette-enrichments-gpt]] plugin, which can run prompts through GPT-4 Vision.
