# datasette-upload-dbs

## Description

datasette-upload-dbs is a plugin for [[Datasette]] that lets users upload SQLite database files directly to a Datasette instance. The source credits [[Datasette Cloud]] work with driving improvements to the plugin, which places it within the broader Datasette ecosystem that the product work is shaping. Version 0.3 was released on 2023-08-10. In the source post, the plugin is a secondary item rather than a main subject.
