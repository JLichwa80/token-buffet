# datasette-plot

## Description

datasette-plot is a new [[Datasette]] plugin for building data visualizations. [[Alex Garcia]] released it in December 2023 as part of the [[datasette-cloud|Datasette Cloud]] collaboration. It is the first item in the weeknotes, which marks it as the headline development of the month. Its introduction was published on the Datasette Cloud blog. It extends the Datasette plugin ecosystem described throughout the post, using the [[plugin system]].
