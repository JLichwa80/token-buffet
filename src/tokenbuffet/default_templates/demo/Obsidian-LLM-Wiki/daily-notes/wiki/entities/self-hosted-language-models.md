# Self-hosted language models

## Description

Self-hosted language models are large language models that run on the user's own computer rather than through a hosted API. Simon Willison's weeknotes describe bringing them into [[LLM]] through plugins, specifically [[llm-gpt4all]] and [[llm-mpt30b]]. The motivation was a camping trip without access to [[OpenAI]] APIs, which made local models necessary. Once installed, self-hosted models can be used through the same Python API as hosted models.
