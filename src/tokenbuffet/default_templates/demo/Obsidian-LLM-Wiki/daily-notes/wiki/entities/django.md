# Django

## Description

Django is a Python web framework and the subject of the plugin system that [[Simon Willison]] built in September 2024. Willison's talk at [[DjangoCon US 2024]] focused on plugin systems for Django, and he released [[DJP]] to add this capability to the framework. Several other releases in the weeknotes are Django plugins, including `django-plugin-datasette`, `django-plugin-blog`, `django-plugin-database-url`, and `django-plugin-django-header`. These packages show how Django is extended through the plugin architecture that DJP enables. Django is the central framework connecting the conference talk, the DJP release, and the plugin ecosystem described in the post.
