# Gemini Chat App

## Description

The Gemini Chat App is a browser-based LLM chat interface hosted at tools.simonwillison.net that talks directly to [[Gemini]] models. It supports the newer gemini-1.5-flash-8b-exp-0827 model. Compared with the other tools, it is described as a more traditional chat interface. The author built it to test those models and to experiment with streaming responses from the Gemini API in the browser. It is one of the three LLM-powered tools in [[simonw/tools]].
