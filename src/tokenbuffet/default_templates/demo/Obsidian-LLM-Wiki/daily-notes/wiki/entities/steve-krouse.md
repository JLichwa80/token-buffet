# Steve Krouse

## Description

Steve Krouse is the founder of [[Val Town]] and co-host of a livestream that [[Simon Willison]] describes. He runs a series of live coding sessions in which he works with different guests. In one of these sessions, Krouse and a guest built an implementation of [[RAG]] against Simon Willison's blog, using a BM25-style [[Full-text search]] index instead of vector embeddings. The session was later turned into an annotated video write-up. Krouse is linked to the Val Town organization and to this search-based RAG demonstration.
