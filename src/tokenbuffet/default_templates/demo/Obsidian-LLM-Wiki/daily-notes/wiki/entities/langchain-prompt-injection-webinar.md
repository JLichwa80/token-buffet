# LangChain Prompt Injection Webinar

## Description

The LangChain Prompt Injection Webinar is a scheduled online event in which Simon Willison was a speaker the week after the 2023-05-01 weeknotes were written. It was a panel discussion on [[Prompt injection]] attacks against LLMs. The panel also included Willem Pienaar, Kojin Oshiba, Jonathan Cohen, and Christopher Parisien of NVIDIA. Willison planned to restate his argument that AI security problems cannot be solved with more AI. The [[Dual LLM pattern]], proposed the week before, is the related design he discussed in the same weeknotes.
