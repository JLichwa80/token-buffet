# Mastodon

## Description

Mastodon is a decentralised social network. Simon Willison self-hosts his own Mastodon instance at fedi.simonwillison.net. During the simonwillison.net DNS outage, this instance was the most inconvenient casualty: the outage stopped him from posting and from reading his timeline. Because the instance is hosted on a separate domain, its failure shows that a [[DNS]] problem can reach beyond the main website to other services that depend on the same domain name system.

In February 2023, Twitter announced it would end all free bots. It reversed that decision a few days later, but by then the author had already moved a bot to Mastodon. The author also runs a Covid sewage bot on Mastodon that posts a screenshot of the latest Covid sewage numbers for parts of the Bay Area every morning, built with scheduled GitHub Actions and the toot Python tool.
