# Claude 3 Haiku

> Stub created by the ingest candidate gate (prose+named) — [[sources/2024-09-06-weeknotes_32f8a8]] names this without treating it. Will be filled by the next ingest of a source that does.

Claude 3 Haiku is an Anthropic LLM that powers the haiku tool on tools.simonwillison.net. The tool requests camera access and uses the model to write a haiku about the scene it sees. The author notes that the project is built around a pun on the model name and the poetic form. The tool was assembled a few months before the post using Claude 3 Opus for AI-assisted development.

> "It uses Anthropic’s Claude 3 Haiku model for this—the whole project is one terrible pun." — [[sources/2024-09-06-weeknotes_32f8a8]]
