# OpenAI DevDay

## Description

OpenAI DevDay is the developer conference where OpenAI made a large set of announcements on the Monday of the second week of November 2023. Simon Willison attended in person and released [[LLM]] 0.12 the same day to support the new GPT-4 Turbo model. That evening he also built the [[ospeak]] CLI tool for OpenAI's new text-to-speech API. The biggest announcement was [[GPTs]], which he later explored in a separate post. The conference is the anchor event for the first half of the weeknotes covered by [[sources/2023-11-22-weeknotes_49168f|the 2023-11-22 weeknotes]].
