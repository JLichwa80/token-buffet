# DJP

## Description

DJP is a plugin system for [[Django]] released by Simon Willison in September 2024. The release is listed as djp 0.3.1 on 2024-09-26. It was written in preparation for a talk at [[DjangoCon US 2024]]. Willison also published a separate blog post introducing DJP. Several Django plugins described in the weeknotes, such as django-plugin-blog, are built as DJP plugins. The project is a concrete example of the conference-driven development described in the source, and it is the main technical outcome of that month's work on [[Plugin system|plugin systems]].
