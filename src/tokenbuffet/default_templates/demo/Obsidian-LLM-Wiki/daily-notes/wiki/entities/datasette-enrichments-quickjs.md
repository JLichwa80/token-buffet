# datasette-enrichments-quickjs

## Description

datasette-enrichments-quickjs is a [[Datasette]] plugin for Datasette Enrichments, released as version 0.1a0 on 9 February 2024. It uses the `quickjs` Python package, a wrapper around the QuickJS engine, to run a custom JavaScript function against every row in a table and populate a new column. The author noted that QuickJS appears to provide a robust sandbox with both memory and time limits. The author said the plugin opens up new possibilities for Datasette and planned to write more about it.
