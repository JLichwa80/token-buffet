# DjangoCon US 2024

## Description

DjangoCon US 2024 was a conference for the Django web framework community, held in Durham, North Carolina in September 2024. Simon Willison attended and gave a talk on plugin systems. The talk led him to build and release [[DJP]], a new plugin system for [[Django]], so the event directly shaped his software work that month. Willison also wrote a blog post summarizing the conference themes. In the weeknotes, the event is a central milestone linking his travel, his speaking, and his open source releases.
