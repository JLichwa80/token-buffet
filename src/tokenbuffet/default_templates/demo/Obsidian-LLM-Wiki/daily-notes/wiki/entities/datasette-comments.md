# Datasette Comments

## Description

Datasette Comments is a Datasette project, published as `datasette-comments` on GitHub, that adds commenting to Datasette data. It is also referred to as the "Datasette comments plugin." The 2024-02-27 weeknotes group it with [[entities/datasette-enrichments|Datasette Enrichments]] as a feature that [[entities/simon-willison|Simon Willison]] and [[entities/alex-garcia|Alex Garcia]] wanted to be in good shape for NICAR 2024. At that time it was part of the feature set being prepared for [[entities/datasette-cloud|Datasette Cloud]]. The source gives no further detail about how it works.

Datasette Comments lets people leave comments on individual rows within a Datasette instance, so that collaborators can work together on finding stories in the data. [[entities/alex-garcia|Alex Garcia]] released the first version in December 2023 as part of ongoing work to build out [[entities/datasette-cloud|Datasette Cloud]]. The plugin's features include replies, reaction emoji, hashtags, and the ability to mention other users, as shown in a screenshot in the source post.

Alex Garcia was already building datasette-comments by the 2023-11-22 weeknotes, which describe it as an excellent new plugin that will let Datasette users collaborate on data by leaving comments on individual rows. That places development in November 2023, before the December 2023 first release. [[entities/simon-willison|Simon Willison]] describes the plugin as ideal for collaborative investigative reporting. In those weeknotes, it is one of the features Simon highlights as the team's current focus on Datasette Cloud.
