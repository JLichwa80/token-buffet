# GitHub Pages

## Description

GitHub Pages is the static hosting service that publishes the [[simonw/tools]] repository at tools.simonwillison.net. Because the tools are pure HTML and JavaScript, they need no server-side code and can be served directly from the repository. The author values this because it removes the need to think about hosting for these small tools. GitHub Pages is the deployment mechanism that makes the single-file tool approach practical.
