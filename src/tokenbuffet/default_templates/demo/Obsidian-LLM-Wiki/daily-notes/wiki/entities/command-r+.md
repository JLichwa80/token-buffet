# Command R+

## Description

Command R+ is a large language model from Cohere, released under an open license. The source author describes it as an excellent model. It was released the week before the post. On April 10, 2024, it reached position 6 on the [[LMSYS Chatbot Arena Leaderboard]]. The author calls this the highest ranking ever for an open-weights model. The source includes it for this leaderboard milestone. It is compared against [[Google Gemini Pro 1.5]], [[GPT-4 Turbo]], and [[Mixtral 8x22B]] in the same review.
