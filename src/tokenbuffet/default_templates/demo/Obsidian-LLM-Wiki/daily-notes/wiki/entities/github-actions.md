# GitHub Actions

## Description

GitHub Actions is GitHub's built-in automation service for running workflows on a schedule or in response to events. In the 2023-02-09 weeknotes, the author used scheduled GitHub Actions to run his [[Mastodon]] bot, which posts Covid sewage screenshots every morning, and documented the setup in the [[TIL]]. The approach lets a small bot run without a dedicated server. It is the hosting mechanism behind the covidsewage bot and is linked to the [[toot]] library, which the bot uses to post.
