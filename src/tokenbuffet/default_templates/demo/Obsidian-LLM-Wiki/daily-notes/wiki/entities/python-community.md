# Python community

## Description

The Python community is the group of developers and users of the Python language. In his [[PyCon US 2024]] keynote, "Imitation intelligence", the author argues that this community has a unique opportunity and responsibility to help steer [[Large Language Models]] technology in a positive direction. The keynote reflects on the author's work with LLMs over the past couple of years, framed around [[Imitation intelligence]]. The source also suggests that [[Datasette]] should take part in the PyCon sprints so the project can contribute to the community.
