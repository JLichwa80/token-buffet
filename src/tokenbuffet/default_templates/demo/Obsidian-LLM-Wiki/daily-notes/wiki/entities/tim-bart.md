# Tim Bart

## Description

Tim Bart is a person who helped the author run Python inside a WebAssembly sandbox. After the author publicly complained about how difficult this was, Bart found a working example. That example used [[wasmtime]] and the Python WASM build released by VMware Labs. The author then built their own version inspired by Bart's example, which is documented in the TIL. Bart's contribution is the reason the author was able to run untrusted Python in a sandbox for the first time.
