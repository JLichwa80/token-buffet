# Niche Museums

## Description

Niche Museums is a website that catalogues small, unusual museums. Simon Willison maintains it as a personal project. After a hiatus of several months, he added three new museums: the Pioneer Memorial Museum, the Misalignment Museum, and the Mattie Leeds Sculpture Garden. To celebrate these visits, he upgraded the display of the site's photo galleries by switching them to the PhotoSwipe library. The work is tracked in a GitHub issue in the museums repository and required a set of code changes linked from the post. It is the main subject of the site-related work the post describes for that week.
