# Replicate

## Description

Replicate is a hosting platform for machine learning models. It hosted [[Llama 2]] when that model launched, and the author initially mistook the release for a tip about a new [[LLM]] that was about to appear there. The llm-replicate plugin, version 0.3 released 2023-07-20, lets the [[LLM]] command-line tool use models hosted on Replicate, and it is the reason the author could add Llama 2 support so quickly. Replicate's role here is as a model host that other tools can reach through a [[Plugins|plugin]].
