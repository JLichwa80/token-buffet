# datasette-atom

## Description

datasette-atom is a [[Datasette]] plugin that adds an Atom output format to Datasette tables, so table contents can be consumed as an [[Atom feed]]. The source lists its version 0.9 release, dated 2023-03-14, among the releases from that period, with 12 releases in total. The plugin relates to the Atom feed theme that runs through the newsletter and the blog. It is one of several Datasette plugins maintained by Simon Willison, and the source mentions it only in the releases list.
