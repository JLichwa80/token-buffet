# llm-claude-3

## Description

llm-claude-3 is an LLM plugin released by [[entities/simon-willison|Simon Willison]] that lets the `llm` tool interact with the [[entities/claude-3|Claude 3]] family of models. Version 0.4, released on 2024-06-20, added support for [[entities/claude-3-5-sonnet|Claude 3.5 Sonnet]], which had launched shortly before the weeknotes were written. Willison noted that he needed to upgrade some of his own LLM-powered [[entities/datasette|Datasette]] plugins to take advantage of the new model. The plugin appears in the weeknotes' release list alongside datasette 0.64.8.

Version 0.3 of llm-claude-3 was released on 2024-03-13, giving access to Anthropic's new Claude 3 model family. Willison assessed that Opus feels better than GPT-4 at most things, and that Haiku is slightly cheaper than GPT-3.5 Turbo while offering image input support at the lowest price point he had seen anywhere. In the weeknotes, Willison described the plugin as providing access to the new Claude 3 models from his [[entities/llm|LLM]] tool, which connects the Claude 3 models to that command-line workflow.
