# Llama 3

## Description

Llama 3 is a large language model that landed on a Thursday shortly before Simon Willison's 23 April 2024 weeknotes. In the source, its release is the immediate motivation for a week of plugin work: he updated a whole set of [[LLM]] plugins to work with it and documented how to access it from the terminal using the LLM tool. The source also names several other models the author works with across plugins, including Claude 3, GPT-4 Turbo, and Mistral models. Its use in the source is as a plugin integration target rather than as a subject of evaluation. A related but separate page covers the 70B variant, [[llama-3-70b]], which appears in a different source only as a leaderboard comparison point.
