# llm-embed-onnx

## Description

llm-embed-onnx is an [[LLM]] plugin released as version 0.1 on 28 January 2024. It is a thin wrapper around onnx_embedding_models by Benjamin Anderson, which in turn wraps the ONNX Runtime. The plugin makes several new [[Embeddings|embedding models]] available for use with LLM. The author lists the available models in the plugin's README. The plugin is one of the new LLM plugins highlighted in the source post.
