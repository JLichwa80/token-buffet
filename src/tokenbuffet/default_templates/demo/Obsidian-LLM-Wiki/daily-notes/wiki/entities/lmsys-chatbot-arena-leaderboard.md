# LMSYS Chatbot Arena Leaderboard

## Description

The LMSYS Chatbot Arena Leaderboard is a public ranking of language models, used as a benchmark of model quality. Rankings are based on comparative evaluation of model responses. In the source, [[Command R+]] from [[Cohere]] reached position 6 on the leaderboard, which the author describes as the highest ever ranking for an [[Open weights model|open weights model]]. The leaderboard is therefore the reference point for that claim, and it is cited as evidence for the strength of Command R+.
