# datasette-homepage-table

## Description

datasette-homepage-table is a [[Datasette]] plugin that displays a chosen table as the homepage of a Datasette instance. Version 0.2 was released on 2024-01-31. Simon Willison said he had wanted this feature for a while for his own use. A user on the Datasette Discord requested it, and the plugin turned out to be quick to build. It is listed among the new plugins for Datasette in the [[sources/2024-02-09-weeknotes_1bab97|2024-02-09 weeknotes]], as a small example of the quick, request-driven plugin development described there.
