# Alex

## Description

Alex is a collaborator of [[Simon Willison]] who works on Datasette and is responsible for implementing the JSON API changes planned for [[Datasette 1.0]]. Alex and Simon worked together on a final design for the API, which Alex documented in GitHub issue #2360. Alex is now building the implementation, and the team hopes to land it and ship it as an alpha release once it is ready for people to try. Alex's work is driven in part by the need of [[Datasette Cloud]] for a stable [[JSON API]], which makes Alex's implementation a key dependency for the Datasette 1.0 milestone.
