# Datasette Studio

## Description

Datasette Studio is an experimental alpha release (0.1a0, dated 2024-02-18) of [[Datasette]] pre-configured with a set of useful plugins. It is installed with `pipx install datasette-studio`, which provides Datasette under the separate alias `datasette-studio`. The entire package is defined by a single `pyproject.toml` file with five dependencies and a custom `console_scripts` entry point, with no additional Python code. The author describes it as an experiment in bundling plugins that is still very experimental, but pointing in a promising direction.
